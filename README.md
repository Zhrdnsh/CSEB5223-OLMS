CSEB5223-OLMS (Online Local Mart System)

Project Description
- The Online Local Mart System (OLMS) is developed for small local grocery stores to improve the process of managing and providing product information to customers. The system aims to reduce repetitive customer enquiries, ease the administrative workload of small grocery store owners, and provide customers with convenient access to up-to-date product information.
